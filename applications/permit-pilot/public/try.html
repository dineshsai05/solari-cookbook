How to interpret the report
  • Current status: the permit-level status observed at capture time.
  • Review cycles: historical departmental decisions, grouped by submitted date. An old denial is not automatically a current problem.
  • Linked checklist: AI connects comments to text in selected applicant responses. Quotes are checked against extracted source text.
  • Coverage: only selected files and bounded text are read. Drawings are not verified. Missing evidence means not found in the reviewed excerpts.
  • Change detection: compares successful captures of the same permit on the same host. Historical reconstruction is explicitly labelled and is not an observed past snapshot.

Before you run

  • Use a public permit number; do not upload private documents.
  • Anyone with a generated report link can read it.
  • Download important results. Free hosting has usage and storage limits.
  • Runs have a daily allowance. No payment or account is required.

The example and instructions stay available here even when the live trial is offline. This trial is not an always-on monitoring service.
